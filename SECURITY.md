# Security Policy

## Supported versions

Text Diff is currently an early-stage static web app. Security fixes should target the latest version on the default branch.

## Reporting a vulnerability

Please report security issues by opening a private security advisory on GitHub if available, or by contacting the maintainer directly through the repository owner profile.

When reporting, include:

- A clear description of the issue.
- Steps to reproduce it.
- The browser and operating system used.
- Whether the issue involves stored text, pasted text, or future API/AI behavior.

## Security and privacy expectations

- Local diffing should not send user text over the network.
- Any future AI feature that sends text to an API must be opt-in and clearly documented.
- Dependencies should be reviewed before updates or additions.
